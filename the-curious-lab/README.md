# THE CURIOUS LAB

A Next.js portfolio starter for Opeyemi Ogunbona, built around the approved warm editorial / colourful 3D reference.

## Included
- Responsive sidebar navigation and homepage
- About, Work, Experiments, Notes and Contact pages
- Dynamic case-study pages for five designed product concepts: Pawluck, Ona, Ajo, Hallchop and Cura HMO
- Central project data in `data/projects.ts`
- Central profile/contact details in `data/profile.ts`
- CSS-built abstract hero artwork and project preview panels

## Run locally
1. Install Node.js 20 or later.
2. Extract the ZIP and open the project folder in a terminal.
3. Run `npm install`.
4. Run `npm run dev`.
5. Open http://localhost:3000.

## Before publishing
- Contact details are configured in `data/profile.ts` (email, phone and LinkedIn).
- Add your approved portrait and real project screenshots to `public/images` and update the relevant components.
- Review all copy and links before deployment.

## Deploy
Push the project to a Git repository and import it into Vercel, or use another host that supports Next.js. Set the production environment according to the host's Next.js instructions.
